# Academia de Programação e Cibersegurança

Biblioteca de cursos progressivos do zero ao avançado, com aulas práticas, exercícios diários, projetos, revisões e desafios.

## Estrutura

- `courses/python/` — Python do zero ao avançado
- `courses/cybersecurity/` — Cibersegurança defensiva do zero ao avançado
- `courses/javascript/` — plano curricular preparado para expansão
- `courses/java/` — plano curricular preparado para expansão
- `courses/cpp/` — plano curricular preparado para expansão
- `courses/go/` — plano curricular preparado para expansão
- `courses/rust/` — plano curricular preparado para expansão
- `courses/sql/` — plano curricular preparado para expansão

## Filosofia

Cada curso é dividido em níveis, módulos, aulas e dias de prática. A meta é aprender construindo, testar o conhecimento e terminar cada módulo com um projeto.

> O material de cibersegurança é orientado para defesa, laboratório autorizado, análise e hardening. Exercícios ofensivos devem ser realizados apenas em sistemas próprios ou explicitamente autorizados.
