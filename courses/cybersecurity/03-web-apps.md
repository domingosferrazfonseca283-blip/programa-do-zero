# Cibersegurança — Volume 3: Segurança Web

HTTP, cookies, sessões, autenticação, autorização, validação de entrada, headers, TLS, APIs, dependências e configuração segura.

Laboratórios apenas em aplicações deliberadamente vulneráveis e ambientes autorizados. Para cada falha: compreender causa, reproduzir em laboratório, identificar impacto, corrigir e escrever teste de regressão.

Projeto: auditoria defensiva de uma aplicação local.
