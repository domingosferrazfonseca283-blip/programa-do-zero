# Cibersegurança — Projeto Final: Mini-SOC Defensivo

## Fases
Escopo → laboratório isolado → logs → baseline → eventos simulados → detecções → triagem → evidências → relatório → melhoria.

## Entregáveis
Diagrama, inventário de fontes, cinco ou mais detecções, procedimentos de triagem, três incidentes simulados, checklist de recuperação e lições aprendidas.

O projeto permanece exclusivamente em ambiente próprio/autorizado.
