# Controles Básicos de Segurança

## Objetivo
Transformar princípios de segurança em controles verificáveis.

## Controles
- Inventário de ativos.
- Contas individuais.
- Menor privilégio.
- MFA quando disponível.
- Atualizações.
- Backups testados.
- Logs relevantes.
- Proteção de endpoints.
- Segmentação adequada.
- Revisão periódica.

## Exercício
Para uma VM própria de laboratório, criar uma tabela: controle, estado atual, evidência, ação corretiva e data de revisão.
