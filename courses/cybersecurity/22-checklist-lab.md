# Checklist do Laboratório de Cibersegurança

## Antes
- [ ] Sistemas próprios ou autorização explícita.
- [ ] Escopo documentado.
- [ ] Rede de laboratório isolada quando necessário.
- [ ] Backups/snapshots disponíveis.

## Durante
- [ ] Registrar alterações.
- [ ] Preservar evidências.
- [ ] Evitar impacto fora do escopo.
- [ ] Reverter alterações quando necessário.

## Depois
- [ ] Restaurar ambiente.
- [ ] Documentar resultados.
- [ ] Corrigir configurações.
- [ ] Validar recuperação.

Regra permanente: os exercícios ofensivos, quando existirem para fins educacionais, devem ocorrer apenas em ambientes deliberadamente preparados e autorizados.
