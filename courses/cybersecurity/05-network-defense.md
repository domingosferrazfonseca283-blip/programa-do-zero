# Cibersegurança — Defesa de Redes

Estude IP, TCP/UDP, DNS, HTTP/HTTPS, DHCP, NAT, roteamento, VLAN, firewall, VPN e segmentação.

Desenhe uma rede de laboratório com utilizadores, servidores, administração e serviços públicos. O objetivo é limitar comunicação desnecessária.

Para cada conjunto de logs responda: o que aconteceu, quando, qual sistema, qual conta, qual evidência, qual hipótese, qual ação defensiva e que informação falta.

Projeto: laboratório de rede isolado com tráfego benigno conhecido e painel simples de eventos.
