# Análise Defensiva de Logs Web e DNS

## Fontes
Logs de servidor web, DNS, autenticação e aplicação.

## O que observar
Horário, origem, destino, método, código de resposta, frequência, erros e correlação entre eventos.

## Exercício
Usar logs sintéticos para construir uma linha temporal e separar eventos normais, suspeitos e inconclusivos.

## Relatório
Registrar evidência, hipótese, confiança, impacto possível e próxima verificação.

## Segurança
Não coletar ou analisar tráfego de terceiros sem autorização.
