# Segurança Web

## Fundamentos
Validação de entrada, saída segura, autenticação, autorização, sessões, cookies, TLS, cabeçalhos, dependências e gestão de segredos.

## Modelagem defensiva
Identificar ativos, fronteiras de confiança, dados sensíveis e pontos de entrada.

## Laboratório
Usar somente uma aplicação local própria ou deliberadamente vulnerável. Documentar risco, evidência, mitigação e teste de regressão.

## Exercícios
- Identificar entradas que precisam de validação.
- Separar autenticação de autorização.
- Criar testes para acesso permitido e negado.
- Verificar que segredos não aparecem em logs.

## Regra
Não testar sistemas de terceiros sem autorização explícita.
