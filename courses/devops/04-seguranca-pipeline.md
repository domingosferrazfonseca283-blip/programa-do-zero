# Segurança no Pipeline

## Controles
Dependências, testes, análise de qualidade, gestão de segredos, permissões mínimas, artefatos, ambientes e aprovação de mudanças.

## Laboratório
Criar uma pipeline local que execute testes, verifique configuração insegura simulada e produza um artefato.

## Boas práticas
Nunca colocar credenciais no código ou no repositório. Usar variáveis/secret stores apropriados ao ambiente.

## Exercício
Documentar quais controles bloqueiam uma alteração insegura e quais apenas geram alerta.
