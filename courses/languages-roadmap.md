# Roadmap para outras linguagens

A coleção pode ser expandida para cursos longos e independentes.

## JavaScript / TypeScript
Fundamentos → DOM → Node.js → TypeScript → APIs → testes → arquitetura → segurança web → projeto final.

## Java
Fundamentos → OOP → Collections → exceções → streams → concorrência → JVM → Spring → APIs → testes → projeto final.

## C
Memória → ponteiros → arrays → structs → ficheiros → compilação → debugging → sistemas → projeto final.

## C++
C moderno → classes → STL → RAII → templates → smart pointers → concorrência → performance → projeto final.

## C#
Fundamentos → OOP → LINQ → async → .NET → ASP.NET → APIs → testes → projeto final.

## Go
Sintaxe → structs → interfaces → packages → concorrência → HTTP → testes → serviços → projeto final.

## Rust
Ownership → borrowing → lifetimes → traits → enums → error handling → async → crates → sistemas → projeto final.

## SQL
Relacional → SELECT → joins → agregações → subqueries → índices → transações → modelação → otimização → projeto final.

## Escala dos cursos

Uma versão extensa pode ser organizada em volumes de aproximadamente 100–200 páginas, com vários volumes por linguagem. Isso é mais prático do que colocar milhares de páginas num único ficheiro e torna cada módulo descarregável e estudável.

Cada linguagem deve ter:
- teoria simples;
- exemplos;
- exercícios diários;
- desafios;
- projetos;
- testes de revisão;
- projeto final;
- glossário;
- checklist de competências.
