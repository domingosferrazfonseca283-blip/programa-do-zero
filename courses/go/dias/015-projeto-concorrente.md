# Dia 15 — Projeto: processador concorrente

## Objetivo
Construir um projeto integrando os conceitos dos primeiros 15 dias.

## Requisitos
Crie um processador que:
1. receba uma lista de tarefas;
2. processe tarefas concorrencialmente;
3. comunique resultados por channels;
4. permita cancelamento por context;
5. trate erros;
6. tenha testes.

## Entregáveis
- código organizado;
- testes;
- README;
- explicação da estratégia de concorrência;
- lista de decisões técnicas.

## Critério de domínio
Você deve conseguir explicar quando usar goroutines, channels e quando uma solução sequencial seria melhor.
