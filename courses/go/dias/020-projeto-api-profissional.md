# Dia 20 — Projeto profissional em Go

## Projeto
Construir uma API de inventário.

## Requisitos
- HTTP;
- persistência;
- validação;
- autenticação/autorização em laboratório;
- middleware;
- testes;
- logs;
- configuração;
- documentação;
- tratamento de erros;
- CI.

## Critério
O projeto deve ser compreensível para outra pessoa sem explicação oral.
