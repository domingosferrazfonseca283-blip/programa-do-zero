# Dia 23 — Pacotes e API pública

## Objetivo
Projetar APIs de pacotes claras.

## Estude
- exportação;
- nomes;
- documentação;
- dependências;
- compatibilidade.

## Exercício
Crie um pacote pequeno com API pública mínima.

## Desafio
Faça uma revisão procurando funções exportadas que não deveriam ser públicas.
