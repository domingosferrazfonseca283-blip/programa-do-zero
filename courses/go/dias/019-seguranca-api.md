# Dia 19 — Segurança de API em Go

## Objetivo
Aplicar práticas defensivas.

## Estude
- validação de entrada;
- autenticação;
- autorização;
- gestão de segredos;
- limites de requisições;
- logs sem dados sensíveis.

## Exercício
Adicione autorização por função a uma API local.

## Desafio
Faça uma revisão de segurança e documente cinco riscos e respectivas mitigações.
