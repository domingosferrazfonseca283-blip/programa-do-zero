# Dia 15 — Projeto API em C#

## Projeto
Construa uma API de tarefas.

## Requisitos
- endpoints CRUD;
- validação;
- camada de serviço;
- persistência;
- tratamento de erros;
- autenticação/autorização em laboratório;
- testes;
- documentação.

## Critério de domínio
Explique o fluxo completo de uma requisição desde HTTP até persistência e retorno da resposta.
