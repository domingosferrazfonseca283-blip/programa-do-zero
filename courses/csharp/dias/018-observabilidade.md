# Dia 18 — Logging e observabilidade

## Objetivo
Tornar uma aplicação diagnosticável.

## Estude
- logs estruturados;
- níveis de log;
- métricas;
- tracing;
- correlation/request ID.

## Exercício
Adicione logging estruturado a uma API.

## Desafio
Defina quais eventos são importantes para diagnosticar uma falha sem registrar segredos ou dados desnecessários.
