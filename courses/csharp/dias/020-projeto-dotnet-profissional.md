# Dia 20 — Projeto .NET profissional

## Projeto
Construir uma API de gestão de inventário.

## Requisitos
- ASP.NET;
- EF Core;
- arquitetura em camadas;
- validação;
- autenticação/autorização em laboratório;
- testes;
- logging;
- documentação;
- CI.

## Critério
O projeto deve possuir fronteiras claras entre domínio, aplicação, infraestrutura e transporte.
