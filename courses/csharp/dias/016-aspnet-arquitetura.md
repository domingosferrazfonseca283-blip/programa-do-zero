# Dia 16 — ASP.NET e arquitetura de API

## Objetivo
Organizar uma API .NET em camadas.

## Estude
- controllers/endpoints;
- services;
- repositories;
- DTOs;
- dependency injection;
- configuração.

## Exercício
Separe uma API de tarefas em apresentação, aplicação e persistência.

## Desafio
Explique por que o domínio não deve depender diretamente do framework HTTP.
