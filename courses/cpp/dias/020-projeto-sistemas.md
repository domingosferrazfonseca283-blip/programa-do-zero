# Dia 20 — Projeto de sistemas em C++

## Projeto
Construa um processador de arquivos local.

## Requisitos
- filesystem;
- classes;
- RAII;
- smart pointers quando apropriado;
- templates;
- algoritmos STL;
- tratamento de erros;
- testes;
- CMake.

## Critério
Explique ownership, tempo de vida dos recursos e decisões de desempenho.
