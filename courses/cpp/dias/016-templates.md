# Dia 16 — Templates

## Objetivo
Aprender programação genérica em C++.

## Estude
- function templates;
- class templates;
- parâmetros de tipo;
- constraints/conceitos.

## Exercício
Crie uma função genérica que encontre o maior elemento de uma coleção.

## Desafio
Crie uma pequena estrutura genérica e explique quais operações seu tipo exige.
