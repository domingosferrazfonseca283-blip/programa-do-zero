# Dia 20 — Projeto SQL analítico

## Projeto
Construir um banco para análise de vendas.

## Requisitos
- modelagem;
- normalização;
- constraints;
- índices;
- views;
- CTEs;
- window functions;
- transações;
- segurança;
- consultas analíticas.

## Entregáveis
1. esquema;
2. dados de teste;
3. consultas;
4. explicação dos índices;
5. relatório analítico.

## Critério
Você deve conseguir explicar não apenas o resultado de cada consulta, mas por que ela foi escrita daquela forma.
