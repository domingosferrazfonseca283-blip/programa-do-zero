# Dia 19 — Segurança de dados

## Objetivo
Aplicar práticas defensivas no acesso a bancos.

## Estude
- princípio do menor privilégio;
- contas e permissões;
- parametrização;
- exposição de dados;
- auditoria;
- backups.

## Exercício
Revise uma aplicação que constrói SQL dinamicamente e substitua entradas perigosas por consultas parametrizadas.

## Desafio
Defina uma matriz simples de permissões para leitura e escrita.
