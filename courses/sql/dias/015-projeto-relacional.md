# Dia 15 — Projeto relacional

## Projeto
Construir o banco de dados de uma pequena loja.

## Requisitos
- modelo relacional;
- tabelas;
- chaves;
- constraints;
- CRUD;
- joins;
- agregações;
- transações;
- índices;
- views;
- consultas para relatórios.

## Entregáveis
1. esquema SQL;
2. dados de teste;
3. consultas;
4. diagrama lógico;
5. explicação das decisões.

## Critério de domínio
Você deve conseguir justificar cada relacionamento, constraint e índice utilizado.
