# Git — Fundamentos

## Conteúdo
Repositório, working tree, staging, commits, branches, merge, rebase como conceito, tags, remotes e recuperação básica.

## Prática
Criar um repositório de laboratório, registrar mudanças em pequenos commits, criar uma branch de funcionalidade e integrar o trabalho.

## Exercícios
Desfazer uma alteração não commitada, localizar um commit e explicar a diferença entre working tree, index e histórico.
