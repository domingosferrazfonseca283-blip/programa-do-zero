# Dia 20 — Projeto de serviço em Rust

## Projeto
Construa um serviço local de processamento de tarefas.

## Requisitos
- módulos;
- traits;
- generics;
- Result;
- persistência;
- concorrência controlada;
- testes;
- logs;
- documentação.

## Critério
Explique ownership, borrowing, lifetimes e sincronização usados no projeto.
