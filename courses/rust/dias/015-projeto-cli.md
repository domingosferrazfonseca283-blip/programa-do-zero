# Dia 15 — Projeto CLI em Rust

## Objetivo
Integrar ownership, collections, iterators, traits, módulos e Result.

## Projeto
Construa uma CLI de tarefas.

## Requisitos
- adicionar tarefa;
- listar tarefas;
- concluir tarefa;
- salvar e carregar dados;
- tratar erros;
- separar módulos;
- testar regras importantes.

## Entregáveis
- código;
- testes;
- README;
- exemplos de uso;
- explicação das decisões de ownership.

## Critério de domínio
Você deve conseguir explicar por que cada referência possui determinado lifetime implícito e por que certas funções recebem ownership em vez de empréstimo.
