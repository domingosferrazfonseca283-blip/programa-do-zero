# Dia 25 — Projeto Full Stack

## Projeto
Construir uma aplicação web completa.

## Requisitos
- frontend;
- backend;
- API;
- banco de dados;
- validação;
- autenticação/autorização em laboratório;
- testes;
- documentação;
- configuração segura.

## Critério
Você deve conseguir explicar a jornada completa dos dados: navegador → API → serviço → banco → resposta.
