# JavaScript — Dia 001: Ambiente e Primeiro Programa

## Objetivo
Executar JavaScript e entender a diferença entre código-fonte e execução.

## Prática
Criar um programa que mostre nome, objetivo de estudo e uma pequena mensagem.

## Exercícios
1. Imprimir três valores.
2. Criar duas variáveis.
3. Alterar uma variável e observar o resultado.

## Desafio
Criar um resumo de estudante usando variáveis e template strings.
