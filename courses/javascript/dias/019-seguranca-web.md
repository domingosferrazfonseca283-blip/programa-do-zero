# Dia 19 — Segurança no JavaScript web

## Objetivo
Reconhecer riscos comuns no código do navegador.

## Estude
- XSS;
- uso seguro de `textContent`;
- validação no cliente e no servidor;
- gestão de tokens;
- não confiar em dados do utilizador.

## Exercício
Substitua inserções HTML inseguras por manipulação segura de texto.

## Desafio
Faça uma revisão de segurança de uma pequena interface e documente riscos e correções.
