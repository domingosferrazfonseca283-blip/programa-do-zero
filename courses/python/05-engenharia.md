# Python — Engenharia de Software

Estude estrutura profissional, separação de responsabilidades, testes unitários e de integração, fixtures, mocks, cobertura, logging, configuração, gestão de segredos, packaging, lint, CI/CD, profiling e revisão de código.

Exercício diário: escolha uma função e escreva 3 casos normais, 2 casos limite e 2 entradas inválidas.

Projeto: transformar um projeto anterior numa aplicação profissional com testes, documentação, CI e configuração por ambiente.
