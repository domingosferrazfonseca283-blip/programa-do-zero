# Python — Volume 19: Dados e Relatórios

## Conteúdo
Leitura de dados, limpeza, validação, transformação, agregação, estatística descritiva e geração de relatórios.

## Exercícios
Detectar valores ausentes, duplicados e inconsistentes; agrupar registros; calcular médias, medianas e frequências; documentar as decisões de limpeza.

## Projeto
Pipeline local de dados com entrada, validação, transformação, relatório e testes.
