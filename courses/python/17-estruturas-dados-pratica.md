# Python — Volume 17: Estruturas de Dados na Prática

## Objetivos
Dominar listas, tuplas, conjuntos, dicionários, deques, heaps e estruturas compostas.

## Laboratórios
1. Agenda de contatos.
2. Fila de atendimento.
