# Python — Plano Prático de 90 Dias

Dias 1–15: fundamentos, funções, coleções, erros, ficheiros e mini-projeto.

Dias 16–30: módulos, JSON, CSV, pathlib, datas, regex, logging, testes, SQLite e inventário.

Dias 31–45: classes, composição, herança, polimorfismo, abstrações, dataclasses, protocolos, testes e projeto.

Dias 46–60: iterators, generators, decorators, context managers, closures, typing, profiling, caching e projeto avançado.

Dias 61–75: HTTP, APIs, validação, autenticação, autorização, SQL, transações, testes, configuração e segurança.

Dias 76–90: arquitetura, packaging, CI, containers, observabilidade, concorrência, asyncio, processos, profiling e projeto final.

Regra: reduzir exercícios difíceis a versões mínimas e aumentar a complexidade progressivamente.
