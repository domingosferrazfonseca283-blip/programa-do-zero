# Python — Plano Prático de 90 Dias

Estude 60–120 minutos por dia: teoria, implementação, exercícios e revisão.

Dias 1–15: ambiente, variáveis, tipos, operadores, entrada, condições, loops, listas, dicionários, strings, funções, escopo, exceções, ficheiros e mini-projeto.

Dias 16–30: módulos, packages, comprehensions, iteráveis, JSON, CSV, pathlib, datas, regex, logging, testes, SQLite e projeto de inventário.

Dias 31–45: classes, métodos, composição, herança, polimorfismo, abstrações, dataclasses, protocolos, exceções próprias, testes e projeto.

Dias 46–60: iterators, generators, decorators, context managers, closures, typing, generics, introspection, profiling, caching e projeto avançado.

Dias 61–75: HTTP, APIs, validação, autenticação, autorização, SQL, transações, testes de API, logging, configuração, segurança e projeto API.

Dias 76–90: arquitetura, packaging, CI, containers, observabilidade, concorrência, asyncio, processos, profiling, segurança de dependências, revisão e projeto final.

Regra: quando um exercício for difícil, reduza-o a uma versão mínima e aumente a complexidade progressivamente.
