## Modelo diário

Cada dia deve conter:
- explicação simples;
- exemplo guiado;
- código para executar;
- exercício de fixação;
- exercício de desafio;
- revisão;
- mini-projeto;
- checklist de competências.

## Exercícios diários — exemplo

### Dia 1
Tema: `print()`, comentários e execução.

Tarefa: criar um programa que apresente nome, cidade e objetivo de estudo.

### Dia 2
Tema: variáveis e tipos.

Tarefa: criar um conversor de idade, peso e altura.

### Dia 3
Tema: operadores.

Tarefa: criar uma calculadora com quatro operações.

### Dia 4
Tema: condições.

Tarefa: validar acesso com idade e estado de uma conta.

### Dia 5
Tema: ciclos.

Tarefa: imprimir uma tabela de multiplicação.

### Dia 6
Tema: coleções.

Tarefa: construir um pequeno catálogo.

### Dia 7
Revisão e projeto semanal.

## Projeto final

Construir um gestor de tarefas com:
- SQLite;
- arquitetura por camadas;
- validação;
- logging;
- testes;
- CLI;
- API;
- autenticação em laboratório;
- documentação.

Este diretório é a base para uma versão extensa do curso, que pode ser dividida em vários volumes para manter cada ficheiro fácil de navegar.
