# Python — Volume 16: Desenvolvimento Seguro

## Conteúdo
Validação de entrada, autenticação, autorização, gestão de segredos, consultas parametrizadas, uploads seguros, logs sem dados sensíveis, dependências, configuração e menor privilégio.

## Laboratório
Usar somente aplicações locais e dados fictícios. Criar testes que comprovem que entradas inválidas são rejeitadas e que usuários não acessam recursos fora de sua autorização.

## Projeto
Auditar defensivamente uma API própria e produzir uma lista de riscos, evidências, correções e testes de regressão.
