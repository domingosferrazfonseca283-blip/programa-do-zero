# Python — Volume 14: Arquitetura de Software

## Conteúdo
Responsabilidades, coesão, acoplamento, camadas, domínio, serviços, persistência, interfaces, dependências, configuração, observabilidade e evolução de sistemas.

## Prática
Reestruturar uma aplicação monolítica pequena em módulos bem definidos sem alterar seu comportamento externo.

## Projeto
Aplicação de tarefas com domínio separado da persistência e da interface, testes por camada e documentação das decisões arquiteturais.
