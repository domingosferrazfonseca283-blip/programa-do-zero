# Python — Volume 11: Banco de Dados e Engenharia

## Conteúdo
Modelagem relacional, SQL com Python, SQLite, transações, constraints, índices, repository pattern, configuração, logs, testes, migrations, packaging e CI.

## Projeto
Aplicação de biblioteca com livros, autores, usuários e empréstimos.

### Requisitos
- CRUD e validação.
- Foreign keys e integridade.
- Transações.
- Consultas parametrizadas.
- Testes unitários e de integração.
- Logs e configuração separada.
- Documentação de instalação.

### Segurança
Nunca concatene entrada do usuário em SQL. Não coloque senhas ou tokens no código ou no repositório. Use dados fictícios.
