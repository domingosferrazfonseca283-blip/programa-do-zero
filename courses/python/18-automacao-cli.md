# Python — Volume 18: Automação e CLI

## Conteúdo
Argumentos de linha de comando, pathlib, arquivos, CSV, JSON, configuração, logging, códigos de saída e tratamento de erros.

## Projeto
Criar uma ferramenta CLI que organiza e analisa arquivos em uma pasta própria, gera relatórios e mantém logs.

## Segurança
O laboratório deve usar somente diretórios autorizados. Evite operações destrutivas por padrão e ofereça modo de simulação.
