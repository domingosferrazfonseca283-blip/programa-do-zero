# Dia 163 — Cancelamento e timeouts assíncronos

## Objetivo
Tratar cancelamento como parte normal do ciclo de vida.

## Prática
Crie uma operação assíncrona com timeout e garanta que recursos sejam liberados mesmo quando a tarefa é cancelada.

## Desafio
Teste:
- conclusão;
- timeout;
- cancelamento;
- erro.

## Checklist
- [ ] Cancelamento é tratado.
- [ ] Recursos são liberados.
- [ ] Testes cobrem interrupções.
