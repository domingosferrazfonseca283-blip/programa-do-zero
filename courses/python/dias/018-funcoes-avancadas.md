# Dia 018 — Funções: Escopo, Argumentos e Reutilização

## Conteúdo
Escopo local/global, argumentos posicionais e nomeados, valores padrão, `*args` e `**kwargs`.

## Exercícios
1. Criar função configurável.
2. Trabalhar com argumentos nomeados.
3. Reaproveitar uma função em três cenários.
4. Identificar dependências globais desnecessárias.

## Desafio
Criar uma pequena biblioteca de funções para validação de dados, sem depender de estado global.
