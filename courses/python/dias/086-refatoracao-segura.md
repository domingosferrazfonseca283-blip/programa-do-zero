# Dia 86 — Refatoração segura

## Objetivo
Melhorar estrutura sem alterar comportamento acidentalmente.

## Processo
1. criar ou confirmar testes;
2. fazer uma alteração pequena;
3. executar testes;
4. rever diferença;
5. repetir.

Nunca faça uma grande transformação sem uma rede de segurança.

## Prática
Escolha uma função grande do projeto e:
- extraia responsabilidades;
- dê nomes melhores;
- reduza duplicação;
- mantenha os testes verdes.

## Desafio
Compare antes/depois e explique por que a nova estrutura é mais fácil de manter.

## Checklist
- [ ] Testes existiam antes da mudança.
- [ ] Fiz mudanças pequenas.
- [ ] Verifiquei comportamento.
- [ ] Documentei decisões importantes.
