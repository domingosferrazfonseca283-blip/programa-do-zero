# Dia 148 — Profiling

## Objetivo
Localizar onde o programa realmente gasta tempo.

## Prática
Escolha uma operação lenta e use uma ferramenta de profiling apropriada para identificar funções dominantes.

## Processo
1. reproduzir;
2. medir;
3. perfilar;
4. identificar gargalo;
5. alterar;
6. medir novamente.

## Desafio
Compare o perfil antes e depois da alteração.

## Checklist
- [ ] Perfil foi obtido.
- [ ] Gargalo foi identificado.
- [ ] Alteração foi validada por medição.
