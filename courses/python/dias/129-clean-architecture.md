# Dia 129 — Clean Architecture

## Objetivo
Comparar diferentes formas de organizar dependências em um sistema.

## Teoria
Clean Architecture enfatiza regras de negócio protegidas de detalhes externos. O princípio central é direcionar dependências para dentro.

## Prática
Mapeie:
- entidades;
- casos de uso;
- interfaces;
- infraestrutura.

## Desafio
Identifique três dependências que poderiam ser invertidas.

## Checklist
- [ ] Sei explicar a direção das dependências.
- [ ] Separei política de detalhe.
- [ ] Identifiquei fronteiras.
