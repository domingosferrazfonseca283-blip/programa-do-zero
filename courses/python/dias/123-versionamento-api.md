# Dia 123 — Versionamento de API

## Objetivo
Evoluir contratos sem quebrar consumidores desnecessariamente.

## Teoria
Mudanças incompatíveis exigem estratégia. O versionamento deve considerar consumidores, migração e compatibilidade.

## Prática
Modele uma alteração incompatível e compare estratégias:
- nova versão;
- compatibilidade temporária;
- migração gradual.

## Desafio
Escreva um plano de retirada de uma versão antiga.

## Checklist
- [ ] Identifiquei mudanças incompatíveis.
- [ ] Defini período de transição.
- [ ] Documentei depreciação.
