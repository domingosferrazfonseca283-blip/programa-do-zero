# Dia 135 — DDD prático

## Objetivo
Usar conceitos de Domain-Driven Design de maneira pragmática.

## Conceitos
- linguagem ubíqua;
- bounded context;
- entidade;
- Value Object;
- agregado;
- evento de domínio.

## Prática
Escolha um domínio do projeto e construa um glossário.

## Desafio
Separe conceitos que parecem iguais, mas pertencem a contextos diferentes.

## Checklist
- [ ] Glossário existe.
- [ ] Termos têm significado preciso.
- [ ] Fronteiras do domínio estão documentadas.
