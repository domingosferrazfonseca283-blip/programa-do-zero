# Dia 167 — Pools de execução

## Objetivo
Controlar quantidade de trabalho concorrente.

## Prática
Use um pool para processar tarefas independentes.

Defina:
- tamanho do pool;
- comportamento de erro;
- coleta dos resultados;
- encerramento.

## Desafio
Compare um pool pequeno e um grande e explique o trade-off.

## Checklist
- [ ] Concorrência é limitada.
- [ ] Resultados são associados às tarefas.
- [ ] Erros não são perdidos.
