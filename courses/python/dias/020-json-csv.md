# Dia 020 — JSON e CSV

## Conteúdo
Troca de dados estruturados, leitura, escrita, validação e diferenças entre formatos.

## Exercícios
1. Exportar tarefas para JSON.
2. Exportar relatório para CSV.
3. Importar dados.
4. Detectar registros incompletos.

## Desafio
Criar uma ferramenta local que converta dados de tarefas entre JSON e CSV, sem apagar o arquivo original.
