# Dia 050 — Projeto API Completa

## Objetivo
Construir uma API local de biblioteca com persistência e qualidade de engenharia.

## Requisitos
- HTTP/REST
- CRUD
- validação
- SQLite
- autenticação de laboratório
- autorização
- testes
- logging
- configuração
- documentação
- revisão de segurança

## Entrega
README, arquitetura, código, testes automatizados, exemplos de utilização e relatório final.

## Critério
O aluno deve conseguir explicar o fluxo completo de uma requisição, do cliente até a persistência e de volta à resposta.
