# Dia 160 — Projeto: biblioteca Python avançada

## Objetivo
Consolidar internals, packaging, testes e qualidade.

## Projeto
Crie uma pequena biblioteca Python com:
- API pública documentada;
- classes e protocolos apropriados;
- validação;
- testes;
- type hints;
- packaging;
- logging quando necessário;
- CI;
- documentação.

## Parte avançada
Inclua pelo menos uma funcionalidade que utilize conscientemente um mecanismo avançado estudado, como descriptor ou protocolo especial.

## Entrega
Explique por que cada mecanismo avançado foi escolhido e quais alternativas foram consideradas.

## Critério
A biblioteca deve ser compreensível para outro programador e instalável em um ambiente virtual limpo.

## Checklist
- [ ] API pública definida.
- [ ] Testes passam.
- [ ] Package instala.
- [ ] CI executa.
- [ ] Decisões técnicas documentadas.
