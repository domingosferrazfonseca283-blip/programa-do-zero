# Dia 155 — Python Data Model

## Objetivo
Entender como objetos Python participam das operações da linguagem.

## Estudo
Explore métodos especiais como:
- __repr__;
- __str__;
- __eq__;
- __lt__;
- __len__;
- __iter__;

## Prática
Crie uma classe que implemente uma pequena parte desse protocolo.

## Desafio
Explique por que respeitar protocolos da linguagem pode produzir APIs mais naturais.
