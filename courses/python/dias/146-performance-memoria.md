# Dia 146 — Performance de memória

## Objetivo
Entender o custo de manter dados em memória.

## Conceitos
- cópia;
- referência;
- alocação;
- streaming;
- generators;
- cache.

## Prática
Processe um conjunto grande de dados em duas formas:
1. carregando tudo;
2. processando incrementalmente.

Compare o consumo de memória.

## Desafio
Escolha a estratégia com base em evidências.

## Checklist
- [ ] Diferenciei memória e tempo.
- [ ] Testei processamento incremental.
- [ ] Medi antes de otimizar.
