# Dia 159 — Packaging profissional

## Objetivo
Organizar um projeto Python para distribuição e instalação reproduzível.

## Prática
Estruture um pacote com:
- código;
- testes;
- metadados;
- dependências;
- configuração de build.

## Desafio
Instale o pacote em um ambiente virtual limpo e execute os testes.

## Checklist
- [ ] Projeto instala em ambiente limpo.
- [ ] Dependências estão declaradas.
- [ ] Testes são executáveis após instalação.
