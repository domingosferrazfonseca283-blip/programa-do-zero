# Dia 71 — Metaprogramação

## Objetivo
Entender como Python permite inspecionar e construir comportamentos dinamicamente.

## Estude
- introspecção;
- `getattr`;
- `setattr`;
- `__dict__`;
- classes como objetos;
- limites da metaprogramação.

## Exercício
Crie um mecanismo simples de registro de classes.

## Desafio
Resolva o problema primeiro sem metaprogramação e depois compare as duas abordagens.

## Critério
Você deve conseguir justificar por que uma solução explícita pode ser preferível a uma solução dinâmica.
