# Dia 055 — Princípios SOLID

## Conteúdo
Responsabilidade única, aberto/fechado, substituição, segregação de interfaces e inversão de dependências.

## Regra
SOLID não é uma coleção de abstrações obrigatórias. Use princípios para resolver problemas reais de manutenção.

## Desafio
Identificar três violações em código fictício e refatorar apenas onde houver benefício.
