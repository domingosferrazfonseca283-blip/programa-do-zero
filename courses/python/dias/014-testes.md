# Dia 014 — Primeiros Testes

## Objetivo
Verificar automaticamente se o código se comporta como esperado.

## Exercícios
Criar testes para soma, validação, criação de tarefas, conclusão e rejeição de dados inválidos.

## Desafio
Encontrar deliberadamente um bug no projeto e escrever primeiro um teste que demonstre o problema; depois corrigir o código e confirmar que o teste passa.

## Revisão
Ao final da segunda semana, refaça um exercício sem consultar o material e explique como você descobriu e corrigiu um erro.
