# Dia 119 — Auditoria e rastreabilidade

## Objetivo
Registrar ações importantes de forma útil para investigação.

## Auditoria deve responder
- quem;
- fez o quê;
- quando;
- em qual recurso;
- resultado;
- contexto necessário.

## Prática
Crie eventos de auditoria para alterações relevantes.

## Desafio
Diferencie log operacional de registro de auditoria e evite armazenar segredos.

## Checklist
- [ ] Ações críticas são rastreáveis.
- [ ] Existe timestamp.
- [ ] O registro não expõe segredos.
- [ ] Retenção foi considerada.
