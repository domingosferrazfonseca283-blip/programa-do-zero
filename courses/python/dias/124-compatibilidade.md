# Dia 124 — Compatibilidade e evolução

## Objetivo
Entender como alterar software mantendo contratos importantes.

## Prática
Pegue uma função ou endpoint existente e faça uma mudança compatível.

Depois faça uma mudança incompatível e documente a diferença.

## Desafio
Crie testes que funcionem como proteção do contrato.

## Checklist
- [ ] Sei distinguir mudanças compatíveis.
- [ ] Testes protegem comportamento público.
- [ ] Alterações incompatíveis são comunicadas.
