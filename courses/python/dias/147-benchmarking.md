# Dia 147 — Benchmarking

## Objetivo
Criar medições reproduzíveis para comparar implementações.

## Prática
Defina um benchmark para uma função crítica do projeto.

Controle:
- tamanho da entrada;
- número de repetições;
- ambiente;
- versão do código.

## Desafio
Explique por que uma única execução não é evidência suficiente.

## Checklist
- [ ] Entrada é controlada.
- [ ] Repetições são suficientes.
- [ ] Resultado é comparável.
