# Dia 104 — Marco do projeto integrador

## Objetivo
Consolidar os conhecimentos adquiridos até aqui em uma revisão profissional.

## Entrega
O projeto deve apresentar:
- requisitos documentados;
- domínio separado;
- persistência;
- serviços;
- interface;
- validação;
- testes unitários e de integração;
- logs;
- métricas básicas;
- configuração por ambiente;
- tratamento seguro de segredos;
- CI;
- documentação.

## Revisão
Faça uma inspeção procurando:
1. duplicação;
2. dependências desnecessárias;
3. erros sem tratamento;
4. testes frágeis;
5. logs sensíveis;
6. configuração espalhada;
7. documentação incompleta.

## Desafio
Corrija pelo menos cinco problemas encontrados e registre o motivo de cada alteração.

## Critério de conclusão
Você deve conseguir explicar o sistema do ponto de entrada até a persistência, justificar as principais decisões e executar os testes de forma reproduzível.

## Checklist
- [ ] Projeto executa.
- [ ] Testes passam.
- [ ] CI passa.
- [ ] Documentação permite reprodução.
- [ ] Decisões arquiteturais estão registradas.
