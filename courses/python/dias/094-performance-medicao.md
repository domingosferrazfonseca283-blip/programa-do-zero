# Dia 94 — Performance orientada por medição

## Objetivo
Evitar otimizações baseadas apenas em intuição.

## Processo
1. definir o problema;
2. criar uma medição;
3. identificar o gargalo;
4. alterar uma coisa;
5. medir novamente;
6. comparar.

## Prática
Compare duas implementações para processar uma coleção. Meça tempo e, quando relevante, memória.

## Desafio
Faça uma otimização e apresente evidência antes/depois.

## Checklist
- [ ] Medi antes.
- [ ] Identifiquei o gargalo.
- [ ] Alterei uma variável por vez.
- [ ] Medi depois.
