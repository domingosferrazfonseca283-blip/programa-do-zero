# Dia 070 — Projeto Integrador

## Objetivo
Integrar Python, SQL, API, testes, arquitetura, observabilidade e segurança.

## Requisitos
Aplicação local completa, documentação, testes automatizados, persistência, API, configuração, logging, revisão de segurança e CI.

## Avaliação
O aluno deve conseguir explicar o sistema, alterar uma funcionalidade e corrigir uma falha sem depender de cópia literal de soluções.
