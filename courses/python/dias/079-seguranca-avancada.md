# Dia 79 — Segurança de aplicações Python

## Objetivo
Fazer uma revisão defensiva de uma aplicação.

## Checklist
- validação;
- autenticação;
- autorização;
- secrets;
- dependências;
- SQL parametrizado;
- uploads;
- logs;
- configuração;
- menor privilégio.

## Exercício
Faça threat modeling de uma API local.

## Desafio
Produza uma lista de riscos, impacto, mitigação e evidência de teste.
