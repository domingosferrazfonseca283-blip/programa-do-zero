# Dia 136 — Projeto: modelagem profissional do domínio

## Objetivo
Reestruturar o projeto integrador a partir do domínio.

## Entrega
Produza:
1. glossário;
2. entidades;
3. Value Objects;
4. invariantes;
5. casos de uso;
6. agregados;
7. eventos;
8. fronteiras entre contextos;
9. testes de domínio.

## Critério
A implementação deve permitir explicar as regras de negócio sem começar pela tecnologia utilizada.

## Checklist
- [ ] Domínio está documentado.
- [ ] Regras críticas têm testes.
- [ ] Infraestrutura está separada.
- [ ] Linguagem do código acompanha a linguagem do domínio.
