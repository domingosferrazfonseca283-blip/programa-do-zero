# Dia 002 — Variáveis e Tipos

## Objetivo
Entender variáveis como nomes associados a valores e reconhecer os tipos básicos mais usados.

## Conceito
```python
nome = "Ana"
idade = 20
altura = 1.70
estudando = True
```

Aqui temos string, inteiro, float e booleano.

## Inspeção
```python
print(type(nome))
print(type(idade))
```

4. Troque os valores de duas variáveis e explique o resultado.
5. Identifique os tipos de dez valores diferentes.
