# Dia 007 — Listas

## Conteúdo
Criação, índice, alteração, `append`, `remove`, iteração e slicing.

```python
notas = [10, 8, 7]
notas.append(9)
for nota in notas:
    print(nota)
```

## Exercícios
1. Criar lista de tarefas.
2. Adicionar e remover itens.
3. Calcular soma e média.
4. Encontrar maior e menor valor.
5. Criar uma nova lista com itens que atendam a uma condição.

## Desafio
Criar um pequeno gerenciador de tarefas em memória com adicionar, listar e concluir.
