# Dia 121 — Design técnico e documentação de decisões

## Objetivo
Aprender a registrar decisões técnicas de forma que outra pessoa consiga entender o sistema.

## Prática
Crie um documento com:
- contexto;
- problema;
- opções consideradas;
- decisão;
- consequências;
- alternativa descartada.

## Desafio
Registre três decisões reais do projeto.

## Checklist
- [ ] O problema está claro.
- [ ] A decisão é justificável.
- [ ] Consequências estão documentadas.
