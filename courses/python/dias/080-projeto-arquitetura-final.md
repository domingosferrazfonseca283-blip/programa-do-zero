# Dia 80 — Projeto de arquitetura

## Projeto
Evolua o projeto profissional Python para uma arquitetura preparada para crescimento.

## Requisitos
- domínio;
- serviços;
- persistência;
- API/CLI;
- testes;
- observabilidade;
- configuração;
- segurança;
- processamento assíncrono quando justificado;
- documentação.

## Entregáveis
1. diagrama da arquitetura;
2. decisões técnicas;
3. testes;
4. threat model;
5. métricas;
6. documentação de operação.

## Critério de domínio
Você deve conseguir defender cada componente com base em uma necessidade concreta, e não apenas em uma moda arquitetural.
