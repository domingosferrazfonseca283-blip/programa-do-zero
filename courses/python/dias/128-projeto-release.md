# Dia 128 — Projeto: release profissional

## Objetivo
Preparar o projeto integrador para uma entrega reproduzível.

## Entrega
O projeto deve conter:
- documentação de arquitetura;
- contrato da API ou interface;
- estratégia de versionamento;
- testes;
- CI;
- configuração;
- migrações;
- observabilidade;
- checklist de segurança;
- runbook de deploy;
- plano de rollback;
- changelog.

## Exercício final
Faça uma release fictícia em ambiente de laboratório.

Registre:
1. versão;
2. mudanças;
3. testes executados;
4. riscos conhecidos;
5. procedimento de deploy;
6. procedimento de rollback.

## Critério de conclusão
Outra pessoa deve conseguir entender o que mudou, executar o projeto e seguir o procedimento de publicação sem depender de conhecimento oculto.

## Checklist
- [ ] Release reproduzível.
- [ ] Documentação atualizada.
- [ ] Testes executados.
- [ ] Rollback documentado.
