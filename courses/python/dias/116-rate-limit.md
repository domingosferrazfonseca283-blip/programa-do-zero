# Dia 116 — Rate limiting

## Objetivo
Controlar a quantidade de operações aceitas por período.

## Conceitos
- limite;
- janela;
- burst;
- rejeição;
- identificação do cliente.

## Prática
Implemente um limitador simples em memória para uma aplicação local.

## Desafio
Defina limites diferentes para operações normais e operações mais custosas.

## Checklist
- [ ] O limite é mensurável.
- [ ] Excesso é tratado.
- [ ] A política está documentada.
