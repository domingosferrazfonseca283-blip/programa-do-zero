# Dia 031 — Iteradores

## Objetivo
Entender como Python percorre dados.

## Conteúdo
`iter()`, `next()`, protocolo de iteração e `StopIteration`.

## Exercícios
Criar um iterador simples, percorrer coleções e explicar o fluxo de execução.

## Desafio
Implementar um iterador que leia registros de um conjunto local sem carregar lógica de apresentação.
