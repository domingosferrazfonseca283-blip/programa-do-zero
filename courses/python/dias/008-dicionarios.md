# Dia 008 — Dicionários

## Objetivo
Representar dados por chave e valor.

```python
aluno = {"nome": "Ana", "idade": 20}
print(aluno["nome"])
aluno["idade"] = 21
```

## Exercícios
1. Criar cadastro de produto.
2. Atualizar um valor.
3. Percorrer chaves e valores.
4. Contar frequências de palavras.
5. Criar uma agenda simples.

## Desafio
Criar um cadastro de tarefas usando um dicionário para cada tarefa e uma lista para armazená-las.
