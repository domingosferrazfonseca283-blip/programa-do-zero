# Dia 003 — Operadores e Expressões

## Conteúdo
Operadores aritméticos, comparação e lógica.

```python
preco = 25
quantidade = 3
total = preco * quantidade
print(total)
```

Comparações produzem valores booleanos:
```python
idade >= 18
10 == 10
5 != 3
```
