# Dia 145 — Performance de CPU

## Objetivo
Identificar gargalos de processamento e escolher algoritmos adequados.

## Teoria
Complexidade assintótica ajuda a prever como o custo cresce com a entrada. Medição real complementa a análise.

## Prática
Compare duas soluções para o mesmo problema e analise:
- tempo;
- complexidade;
- memória;
- legibilidade.

## Desafio
Substitua uma solução quadrática por uma alternativa melhor quando houver justificativa.

## Checklist
- [ ] Analisei complexidade.
- [ ] Medi o comportamento.
- [ ] Comparei custo e legibilidade.
