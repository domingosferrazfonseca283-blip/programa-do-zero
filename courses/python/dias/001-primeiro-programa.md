# Dia 001 — Primeiro Programa em Python

## Objetivo
Ao terminar o dia, você deverá conseguir criar, executar e explicar um programa Python simples, usar `print`, reconhecer strings, números e comentários e investigar erros básicos de execução.

## 1. Conceito
Um programa é uma sequência de instruções que o computador executa segundo as regras da linguagem. Python executa instruções em ordem, salvo quando estruturas de controle alteram esse fluxo.

## 2. Primeiro código
```python
print("Olá, mundo!")
print("Estou começando a programar.")
```

`print()` envia informação para a saída do programa.

## 3. Strings e números
```python
print("Python")
print(10)
print(10 + 5)
print(10 * 3)
```

Texto entre aspas é uma string. Números inteiros podem participar de operações matemáticas.

## 4. Comentários
```python
# Este comentário explica a próxima instrução.
print("Estudar com prática")
```

Comentários ajudam humanos a entender o código e não são executados como instruções normais.

## 5. Erros são parte do aprendizado
Experimente deliberadamente escrever uma chamada inválida em um arquivo de laboratório. Leia a mensagem de erro, localize a linha indicada e corrija o programa. O objetivo não é evitar todos os erros, mas aprender a investigá-los.
