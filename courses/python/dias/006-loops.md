# Dia 006 — Repetição

## Conteúdo
`for`, `while`, `range`, acumuladores e condições de parada.

```python
for numero in range(1, 6):
    print(numero)
```

## Exercícios
1. Imprimir números de 1 a 10.
2. Somar números de 1 a 100.
3. Criar uma tabuada.
4. Contar valores pares.
5. Repetir entrada até uma condição de saída.

## Desafio
Criar um programa que receba vários valores e produza soma, quantidade e média. Defina claramente como o usuário encerra a entrada.

## Atenção
Loops infinitos são um erro comum. Sempre identifique a condição que faz um `while` terminar.
