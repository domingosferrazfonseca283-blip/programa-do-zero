# Dia 153 — Modelo de memória do Python

## Objetivo
Entender referências, objetos, mutabilidade e ciclo de vida.

## Estudo
Analise:
- identidade;
- igualdade;
- referências;
- mutabilidade;
- cópias rasas e profundas;
- coleta de lixo.

## Prática
Crie exemplos que demonstrem a diferença entre alterar um objeto e substituir uma referência.

## Desafio
Investigue um comportamento inesperado de memória e explique a causa.

## Checklist
- [ ] Diferencio identidade e igualdade.
- [ ] Entendo mutabilidade.
- [ ] Sei quando uma cópia é necessária.
