# Dia 015 — Revisão dos Primeiros 15 Dias

## Prova prática
1. Criar um programa do zero.
2. Usar variáveis, condições e loops.
3. Usar listas e dicionários.
4. Dividir a solução em funções.
5. Validar entradas.
6. Persistir dados.
7. Escrever testes básicos.

## Desafio integrador
Construir um pequeno sistema de biblioteca em terminal, com livros fictícios, empréstimos, persistência local e validação.

## Critério
Se houver partes que você só consegue fazer copiando, marque-as para revisão antes de avançar.
