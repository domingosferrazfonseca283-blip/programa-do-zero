# Dia 96 — Release e documentação

## Objetivo
Preparar um projeto para outra pessoa conseguir instalar, executar e compreender.

## Documentação mínima
- objetivo;
- requisitos;
- instalação;
- configuração;
- execução;
- testes;
- arquitetura;
- limitações;
- segurança;
- contribuição.

## Prática
Faça uma revisão completa do README do projeto e escreva instruções reproduzíveis.

## Desafio
Peça a alguém que siga apenas a documentação e identifique pontos ambíguos.

## Checklist
- [ ] Instalação documentada.
- [ ] Configuração documentada.
- [ ] Testes documentados.
- [ ] Arquitetura explicada.
- [ ] Limitações conhecidas registradas.
