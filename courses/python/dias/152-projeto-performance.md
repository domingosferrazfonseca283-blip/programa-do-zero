# Dia 152 — Projeto: otimização orientada por evidências

## Objetivo
Realizar uma otimização completa sem sacrificar correção.

## Entrega
Escolha um problema real do projeto e apresente:
1. sintoma;
2. hipótese;
3. medição inicial;
4. profiling;
5. alteração;
6. medição final;
7. impacto na complexidade;
8. impacto na manutenção.

## Critério
Não basta dizer que ficou mais rápido: apresente evidência e demonstre que os testes continuam passando.

## Checklist
- [ ] Existe baseline.
- [ ] Gargalo foi medido.
- [ ] Otimização foi validada.
- [ ] Correção foi preservada.
- [ ] Trade-offs foram documentados.
