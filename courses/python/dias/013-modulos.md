# Dia 013 — Módulos

## Objetivo
Organizar código em arquivos com responsabilidades claras.

## Prática
Separar o projeto em módulos de domínio, persistência e interface.

## Exercícios
1. Criar módulo matemático.
2. Importar funções.
3. Criar módulo de validação.
4. Reorganizar o projeto do Dia 12.

## Desafio
Eliminar funções duplicadas e explicar a responsabilidade de cada módulo.
