# Dia 057 — Code Review

## Checklist
Correção, legibilidade, testes, segurança, desempenho, manutenção e documentação.

Revisar um pequeno diff e separar problemas críticos de sugestões de estilo.

## Desafio
Produzir revisão factual, apontando evidência e sugestão concreta para cada problema.
