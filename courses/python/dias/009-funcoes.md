# Dia 009 — Funções

## Objetivo
Dividir programas em partes reutilizáveis.

```python
def somar(a, b):
    return a + b
```

## Conteúdo
Parâmetros, retorno, escopo, valores padrão e responsabilidade de uma função.

## Exercícios
1. Função de soma.
2. Função que verifica paridade.
3. Função que calcula média.
4. Função que valida uma regra simples.
5. Dividir um programa anterior em funções.

## Desafio
Refatorar o gerenciador de tarefas do Dia 7 para usar funções pequenas e bem nomeadas.
