# Dia 036 — Dataclasses

## Objetivo
Representar dados de forma clara.

```python
from dataclasses import dataclass

@dataclass
class Livro:
    titulo: str
    autor: str
```

## Exercícios
Converter modelos simples e comparar com classes tradicionais.

## Desafio
Reestruturar entidades do projeto intermediário usando dataclasses quando fizer sentido.
