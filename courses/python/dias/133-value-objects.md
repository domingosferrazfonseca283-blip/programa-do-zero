# Dia 133 — Value Objects

## Objetivo
Representar conceitos do domínio por seus valores e regras.

## Exemplos
- Email;
- Money;
- CPF fictício para laboratório;
- endereço;
- intervalo de datas.

## Prática
Crie um Value Object imutável que valide suas próprias invariantes.

## Desafio
Substitua valores primitivos inadequados por um Value Object no projeto.

## Checklist
- [ ] O conceito tem identidade pelo valor.
- [ ] Invariantes são protegidas.
- [ ] O objeto é difícil de colocar em estado inválido.
