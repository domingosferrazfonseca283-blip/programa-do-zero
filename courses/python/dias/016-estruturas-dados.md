# Dia 016 — Estruturas de Dados na Prática

## Objetivo
Escolher estruturas conforme o problema, não apenas memorizar sintaxe.

## Prática
Comparar lista, tupla, conjunto e dicionário para representar os mesmos dados.

## Exercícios
1. Remover duplicados com `set`.
2. Contar frequências com `dict`.
3. Preservar ordem com lista.
4. Explicar qual estrutura escolheria e por quê.

## Desafio
Construir um contador de palavras que produza um ranking de frequência.
