# Dia 101 — Migrações de banco

## Objetivo
Entender como evoluir o esquema de dados sem perder rastreabilidade.

## Conceitos
- versão do esquema;
- migration;
- upgrade;
- rollback;
- compatibilidade.

## Prática
Modele duas versões de uma tabela e escreva o plano de migração entre elas.

## Desafio
Planeje uma alteração que preserve os dados existentes.

## Checklist
- [ ] Sei por que migrations existem.
- [ ] Planejei a ordem das alterações.
- [ ] Considerei dados existentes.
