# Dia 122 — Contratos de API

## Objetivo
Definir uma API antes de implementar todos os detalhes.

## Prática
Documente endpoints com:
- método;
- caminho;
- parâmetros;
- corpo;
- respostas;
- erros;
- autenticação.

## Desafio
Faça uma revisão procurando ambiguidades no contrato.

## Checklist
- [ ] Entradas estão definidas.
- [ ] Respostas estão definidas.
- [ ] Erros estão definidos.
