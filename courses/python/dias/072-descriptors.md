# Dia 72 — Descriptors

## Objetivo
Compreender o protocolo de acesso a atributos.

## Estude
- `__get__`;
- `__set__`;
- `__delete__`;
- propriedades;
- validação reutilizável.

## Exercício
Crie um descriptor que valide um campo textual.

## Desafio
Implemente um descriptor numérico com limites e mensagens de erro claras.
