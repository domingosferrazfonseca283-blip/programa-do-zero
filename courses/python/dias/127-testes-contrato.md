# Dia 127 — Testes de contrato

## Objetivo
Garantir que componentes mantenham acordos de comunicação.

## Prática
Defina um contrato para um componente e crie testes que validem:
- formato;
- campos obrigatórios;
- tipos;
- erros;
- compatibilidade.

## Desafio
Faça uma alteração no produtor e verifique se o contrato detecta uma quebra.

## Checklist
- [ ] Contrato é executável.
- [ ] Casos válidos e inválidos são testados.
- [ ] Quebras são detectadas cedo.
