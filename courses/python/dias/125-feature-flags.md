# Dia 125 — Feature flags

## Objetivo
Controlar a ativação de funcionalidades sem necessariamente alterar o código implantado.

## Prática
Implemente uma flag simples para habilitar uma funcionalidade em ambiente de laboratório.

## Desafio
Defina:
- valor padrão;
- responsável;
- estratégia de remoção;
- risco de permanecer ativa indefinidamente.

## Checklist
- [ ] Flag tem finalidade clara.
- [ ] Existe valor seguro.
- [ ] Existe plano para removê-la.
