# Python — Web e APIs

## HTTP
Estude cliente/servidor, requests, responses, métodos, headers, status codes, JSON, cookies e sessões.

## REST
Modele recursos e contratos claros. Exemplo conceitual: GET /products, POST /products, PUT /products/10, DELETE /products/10.

## Validação
Valide tipos, campos obrigatórios, limites, formatos e relações entre campos. Nunca assuma que a entrada é confiável.

## Autenticação e autorização
Autenticação responde quem é. Autorização responde o que pode fazer.

## Segurança
Pratique HTTPS quando aplicável, gestão de segredos, validação, queries parametrizadas, rate limiting, logs e menor privilégio.

## Testes
Teste sucesso, entradas inválidas, autenticação, autorização, recursos inexistentes e erros.

## Projeto
API local de biblioteca com utilizadores, livros, empréstimos, pesquisa, persistência, autenticação, autorização, testes e documentação.
Use apenas dados e ambientes controlados ou autorizados.
