# Trilha de Outras Linguagens

Linguagens: JavaScript/TypeScript, Java, C, C++, C#, Go, Rust e SQL.

Cada trilha terá fundamentos, exercícios diários, estruturas de dados, paradigmas, erros e testes, ferramentas, ecossistema, web/APIs quando aplicável, concorrência, performance, segurança, projetos, desafios e revisão.

A meta de grande profundidade será dividida em vários volumes. A quantidade de páginas não será usada para inflar conteúdo; cada volume deve acrescentar conhecimento e prática reais.
